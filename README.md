## ✈️ 航班資訊（國泰航空香港中轉・共 4 航段）

全程搭乘優質國泰航空（Cathay Pacific），均提供機上餐食服務，出發機場一次領取兩張登機證，行李直掛目的地：

### 去程：2027年 4月1日 (四)
- **第一航段**：國泰航空 **CX431**（空中巴士 A330，有餐食）  
  **11:10** 高雄小港 (KHH) 起飛 ➔ **12:50** 香港國際機場 (HKG) T1 落地
- **香港中轉**：轉機時間 **50 分鐘**，**無需重新託運行李（直掛浦東）、無需過境簽證**，沿「轉機/過境」通道安檢前往下一登機門。
- **第二航段**：國泰航空 **CX360**（空中巴士 A330，有餐食）  
  **13:40** 香港國際機場 (HKG) T1 起飛 ➔ **16:25** 上海浦東 (PVG) T2 落地

### 回程：2027年 4月7日 (三)
- **第一航段**：國泰航空 **CX303**（空中巴士 A330，有餐食）  
  **07:20** 上海浦東 (PVG) T2 起飛 ➔ **10:10** 香港國際機場 (HKG) T1 落地
- **香港中轉**：轉機時間 **55 分鐘**，**無需重新託運行李（直掛高雄）、無需過境簽證**。
- **第二航段**：國泰航空 **CX424**（空中巴士 A321，有餐食）  
  **11:05** 香港國際機場 (HKG) T1 起飛 ➔ **12:40** 高雄小港 (KHH) 落地
- **包車返家**：13:30 高雄機場專屬包車平安返家。

## ✨ 核心特色與技術架構

1. **🎨 現代化視覺與玻璃擬態設計 (Glassmorphism)**
   - 採用深夜藍、天空藍與暖橙色的優雅漸層配色主題。
   - 柔和的毛玻璃背景模糊（`backdrop-filter`）與精細邊框高光。
   - 使用原生 `IntersectionObserver` 實現元件進入視窗的平滑淡入動畫（`.fade-in`）。

2. **📍 雙向響應式時間軸導航**
   - **桌面端**：側邊固定懸浮導航列（Timeline Nav），隨著頁面滾動自動追蹤並高亮目前閱讀的日程（D0~D7）。
   - **手機端**：底部橫向滑動導航列（Mobile Bottom Nav），自動置中當前選取的日期項目，並支援點擊平滑滾動跳轉。

3. **📅 智慧日期折疊機制 (Collapsible Sections)**
   - 自動抓取使用者當前時間（換算 UTC+8 台灣/大陸標準時區）。
   - 只要「當前日期 > 行程日期」，系統會將已結束的歷史日程自動收合，優先展開當日或未來的行程。
   - 點擊任一天的日程標頭（Header）均可隨時手動自由切換展開/折疊狀態。

4. **🔗 整合 18+ 篇深度旅遊攻略與即時天氣連結**
   - 完整收錄靈隱寺、西溪濕地、河坊街、西湖一日遊、宋城千古情、塘棲古鎮、周莊水鄉、拙政園、獅子林、虎丘斜塔、七里山塘街、蘇州博物館、寒山寺等景點之達人實測攻略。
   - 內建杭州、蘇州與上海的中國天氣網官方即時天氣連結。

## 🚀 GitHub Actions 自動部署至 GitHub Pages

本專案已完整配置 `.github/workflows/deploy.yml` 自動化部署工作流程。只要將最新程式碼推送到 GitHub 遠端儲存庫 **`2027Travel`** 的 `main` 分支，GitHub Actions 就會自動打包並發布至 GitHub Pages 靜態網站。

### 步驟一：遠端倉庫設定與推播
本機已關聯遠端儲存庫：`https://github.com/v1277chen/2027Travel.git`。於終端機執行：
```bash
# 加入所有更新
git add -A

# 提交更新
git commit -m "feat: 升級為 2027 蘇杭春季 7 日遊行程並整合國泰航空香港中轉與新住宿"

# 推送至遠端 main 分支
git push origin main
```

### 步驟二：於 GitHub 倉庫啟用 Pages 來源
1. 開啟瀏覽器進入 GitHub 倉庫首頁：`https://github.com/v1277chen/2027Travel`
2. 點擊頂部 **「Settings」** 分頁。
3. 於左側功能選單點擊 **「Pages」**。
4. 在 **「Build and deployment」** 區塊中的 **「Source」**（來源）下拉選單切換為 👉 **【GitHub Actions】**。

### 步驟三：檢視自動部署結果
1. 點擊倉庫頂部的 **「Actions」** 分頁，即可看到工作流程運行狀態。
2. 執行完成後，公開造訪網址為：  
   👉 **`https://v1277chen.github.io/2027Travel/`**

## 🛠️ 程式碼維護與函式規格說明

所有的 JavaScript 函式皆包含完整的繁體中文 JSDoc 規範註解：

| 函式名稱 | 參數 (Type) | 回傳值 (Type) | 功能描述 |
|:---|:---|:---|:---|
| `initScrollAnimations()` | 無 | `void` | 運用 `IntersectionObserver` 監控 `.fade-in` 元素進場並觸發淡入動畫 |
| `initTimelineNav()` | 無 | `void` | 監控視窗滾動高度，即時更新桌面側邊欄與手機底部導航的 active 選取狀態 |
| `throttle(func, limit)` | `func: Function`, `limit: number` | `Function` | 函式執行節流器，限制在特定毫秒間隔內僅觸發一次，避免滾動卡頓 |
| `updateNav()` | 無 | `void` | 計算當前視窗中線所在的日程段落 ID 並連動更新各導航按鈕樣式 |
| `initExpandableCards()` | 無 | `void` | 為具備 `.expandable` 的卡片綁定點擊展開/收合高度過渡動畫 |
| `initSmoothScroll()` | 無 | `void` | 攔截內部錨點點擊，執行平滑滾動至目標元素高度 |
| `initCollapsibleDays()` | 無 | `void` | 抓取 UTC+8 日期與各 section 之 `data-date` 比較，自動折疊已過期歷史日程 |
